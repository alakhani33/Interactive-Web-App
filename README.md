# 🚲 Interactive Citi Bike Station Map

This project is a web-based interactive map that visualizes real-time public transport data in New York City. It uses **HTML**, **CSS**, and **JavaScript** (with **Leaflet.js**, **D3.js**, and **Moment.js**) to create an engaging and informative experience for users.

# 🚲 App deployed on Github Pages

https://alakhani33.github.io/Interactive-Web-App/

## 🌐 Features

- 📍 **Live Station Status**: Integrates real-time data from Citi Bike APIs to show current station conditions.
- 🗺️ **Interactive Map**: Built using Leaflet.js with custom icons and colored markers for station categories.
- 📊 **Dynamic Legend**: A live-updating legend displays the latest update time and counts of each station type.
- 🧩 **Layer Control**: Users can toggle visibility for each station category.

## 🚧 Station Categories

- 🟡 **Coming Soon**: Stations not yet installed  
- 🔴 **Empty**: Stations with no available bikes  
- 🟠 **Low**: Stations with fewer than 5 bikes  
- 🟢 **Healthy**: Stations with 5 or more bikes  
- 🔵 **Out of Order**: Installed stations not currently renting bikes

## 🛠️ Technologies Used

- **HTML5**  
- **CSS3**  
- **JavaScript ES6+**
- [Leaflet.js](https://leafletjs.com/)  
- [D3.js](https://d3js.org/)  
- [Moment.js](https://momentjs.com/)  


## 📦 How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Wait a moment for the live Citi Bike data to load and render.
